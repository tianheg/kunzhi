## 为什么要自己做

手上这块 Amazfit 的官方开放平台已经 Deprecated（且只认早已退役的小米账号），能拿数据的唯一现实路径是逆向私有 API：`appid` + `apptoken` 打 `api-mifit*.zepp.com`，逐秒心率走文件索引，睡眠藏在 `band_data` 的 base64 blob 里。

这条路能跑通，但两件事摆不平：**随时可能被封**，而且违反 ToS。

自制不是要造一块比 Zepp 好的表，而是要一块**数据入口自己说了算**的设备。

## 起点：fork 哪一块

候选都在立创开源硬件平台上，硬件设计、BOM、固件齐全：

| 项目 | 平台 | 定位 | 复刻成本 |
|---|---|---|---|
| 腕宝 | ESP32-S3 + AXP2101 | 1.69 寸触摸屏 + 小智 AI 语音 | ¥90 起（作者 BOM 合计 ¥100.66） |
| QF ZERO V2 | ESP32-S3 + HC32L110 副 MCU | 双核低功耗，接近商品级外观 | 未标价 |
| K-Watch 一类 | nRF52840 + Zephyr | 正统低功耗路线 | 器件更贵，固件门槛更高 |

第一块选**腕宝**：BOM 已公开，附带合并固件与外壳文件，照着装就能亮。QF ZERO V2 的双核架构更成熟，留作第二块。

## 成本

**一次性工具**（已有就跳过）

- 热风枪 + 可调电源 + 二手示波器：¥600–1500
- 焊台、镊子、助焊剂、看 0402 的放大镜：¥200–500

**每一版板子**

- PCB 打样：1–4 层 10×10cm 5 片，有免费券（每月两张，需上月有 ≥20 元实单才能续）
- SMT 贴片：经济型 50 元/款起，焊点费 0.1 元/点（1 万点以内）；激光钢网 ¥55
- 1.28 寸圆屏（GC9A01，带触摸）：¥17–37
- MAX30102 心率血氧：模块 ¥11–13，贴片 ¥6.5（1.8V 供电域，裸片必须回流焊）
- ESP32-S3-WROOM-1 N16R8 ¥14.5 / AXP2101 ¥3.76 / 电池 320mAh ¥7.5 / 表带 ¥9.8
- 3D 打印外壳（类尼龙树脂约 ¥50/250g）：¥15–40

**分阶段总额**

- 第一块能点亮、能烧固件：¥300–600
- 一块像样的原型（含心率、外壳、表带）：¥600–1200
- 做到能天天戴（三轮迭代 + 结构重做 + 器件损耗）：¥2000–5000

要对外卖的话，另加 SRRC 型号核准、CE/FCC、锂电 UN38.3，几万起；一旦宣称测心率血氧就撞医疗器械资质。**自用没事，卖基本封死。**

## 需要会什么

| 层 | 内容 | 现状 |
|---|---|---|
| 电路 | 电源通路、I2C/SPI 上拉、充电 IC 外围、模拟供电域分割 | 电路分析路线推进中（阶段 3–5） |
| EDA | 立创EDA 专业版 / KiCad；四层板、铺铜、电源分区、BLE 天线净空区不能铺铜 | 从零 |
| 焊接 | 0402、QFN/DFN、光学封装回流焊 | 从零，建议直接交 SMT |
| 固件 | C/C++、ESP-IDF 或 Zephyr、GC9A01 SPI 驱动、LVGL、FreeRTOS 任务 | 有 ESP32 基础 |
| 电源 | AXP2101 充电、CW2015 电量计、深睡 20µA 级、RTC 唤醒、看门狗 | 最硬的一关，决定能不能戴一天 |
| BLE / App | GATT 服务设计、手机端同步 | 有 Android 侧经验 |
| 结构 | 建模（Fusion 360 / SolidWorks）、3D 打印公差、按键手感、密封 | 从零，防水先放弃 |

电路图反而是最不难的一环（照抄再改），真正吃时间的是**电源调优和结构装配公差**。

## 怎么走

1. **先别画板。** 花 ¥78 买小智 ESP32-S3 手表套件，焊一遍、烧固件、改界面——验证到底要什么功能，比任何电路知识都值钱。
2. **第一块自画板只定三个验收标准**：能点亮、触摸可用、续航 ≥1 天。功能全砍，不加心率。
3. **器件全走 SMT**，不手焊 QFN——预算里宁愿多花 100 块，也别搭进去三个周末。
4. 第二轮再加 PPG、再画外壳。**别在第一版同时做硬件、结构、电源、固件四件事。**

时间预期：业余每周 5–8 小时，第一块能亮 4–8 周，能戴 3–6 个月。

## 明确不做

- 不在第一版追求防水与量产合规
- 不自己做手表 OS，ESP-IDF + LVGL 够用
- 不手焊光学封装与 BGA
