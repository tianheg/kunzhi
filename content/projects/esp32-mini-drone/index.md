## 为什么要做

手表那块的难点在电源调优、四层板与结构公差，第一版就很难有正反馈。无人机反过来：**一块小双面板 + 一个 IMU + 四路电机**，没有屏幕、没有电池管理、没有结构密封，固件还是开源的、编译好的 BIN 直接能刷。

真正要自己动手的地方只剩姿态解算与 PID 那部分——**恰好是纯软件**。用它把「设计 → 下单 → 焊接 → 刷写 → 调试 → 起飞」整条链路跑通，成本比手表低一个量级。

## 两个目标，难度差一档

| | 琛光 E1 Mini | 琛光 E1 Nano |
|---|---|---|
| 主控 | ESP32 30PIN 开发板（免焊） | ESP32-S3-SUPERMINI 模组（**要焊芯片**） |
| PCB 厚度 | 1.6mm（底座按此设计） | 1.2mm |
| 作者标称复刻成本 | ¥45 | 未标 |
| 难度 | 照装能飞 | 作者自己建议先做 Mini 练手 |

两者同一套固件路线（GitHub `songge8/CF-Drone`，Arduino 工程），自带 WEB 遥控器，也支持 QGC 手机 APP 与实体遥控（ELRS / CRSF / SBUS，固件里 SBUS 已软件反向）。

**第一块选 Mini。** Nano 的卖点是「最小」，而最小要用芯片级焊接换——不该拿它当第一次拿烙铁的项目。

## 成本口径

页面上写的 ¥45 是作者列的 **BOM 价**，不是到手价：运费、起购量、买错重买都不含在内。

- **PCB**：小尺寸双面，可走免费券（每月两张）；下单时那条网表错误是去掉了开发板导致的，可忽略
- **焊接**：器件量少，且都在手焊范围内（8520 电机、排针、电容、LED），没必要上 SMT；要上就是钢网 ¥55 + 贴片 50 元/款起
- **电机**：8520 空心杯市场价约 ¥3.5–8 只，**要买 2 只红蓝线 + 2 只黑白线**（转向区分），也可以四只同色靠丝印装
- **桨**：65 / 66 / 75mm 都行，几元一对，轴径必须和电机对应
- **电池**：1S 航模电池另算，支架高 12mm，厚度小于 12mm 的能塞进去（皮筋固定）
- **工具**：焊台、万用表已有就没额外投入；没有的话这是最大一笔

结论：**几百元以内能落地**，比手表项目的工具门槛低得多。

## 器件上的硬约束

- 开发板必须是**没有后缀的 ESP32、30 针**——不是 C3 / S3 / CAM，买错直接废
- 电池必须是 **1S 航模 / 无人机电池**（3.7–4.2V，高放电倍率），普通锂电带不动
- 电机 8520 空心杯，3–3.7V，4–5 万转，轴径 1.0 / 1.2mm 要与桨匹配
- 电机转向、桨叶方向都**必须按 PCB 丝印**装，对角的两个方向一致；调试前先摘桨叶
- 主控板那两个 470µF 电容是给电池兜底的，电池品质好可以不装

## 分步怎么走

1. 下附件里的**物料清单 xlsx**，按 1S 供电链路把器件核一遍（BOM 表直接下单会匹配错，只能当参考）
2. 嘉立创下单 PCB + 自购器件；Nano 页面的固件是 `琛光E1_Nano固件20260823.bin`
3. 手焊：先小件后插件，焊完用万用表量虚焊 / 短路，确认无误再上电
4. 刷固件：开发板首次连接一般不自动进下载模式，**按住 BOOT 再插 USB**，用乐鑫官方 Flash Download Tool
5. 校准 IMU（必做）：调试命令 `ca`，六个姿态各保持 8 秒；`ps` 看结果，roll / pitch 接近 0 才算过（±0.5° 内合格，超 5 重来）
6. 室内起飞：连 `Drone_WIFI` → 浏览器开 `192.168.4.1`（手机记得关流量，否则自动切网）→ 解锁推油门
7. 再往下才是改代码：固件是 Arduino 工程，可换 Arduino IDE 或 QGC 的控制台调试

## 明确不做

- 第一块不做 Nano，不碰芯片级 / 光学封装焊接
- 不碰 GPS、光流、图传——这颗只有 IMU，就是室内手动飞
- 不改用 ESP-IDF 重写固件：现成 Arduino 工程够用，重写等于把项目变成另一个项目
- **不商用**：项目是 CC BY-NC-SA 4.0，禁止商业使用
